A full-featured **Student Management System** built using **Node.js, Express, MongoDB, and EJS**, designed to function like a real **college portal** with secure authentication, attendance tracking, analytics, and a clean modern UI.

---

## 🎓 Project Overview

This system enables educational institutions to efficiently manage:

- Student records  
- Attendance data  
- Analytics and performance  
- Secure admin & student access  
- Exportable reports  

It features a fully responsive, professional UI/UX inspired by actual university portals.

---

## 🚀 Key Features

### 1. 🔐 User Authentication System
- Admin login with secure username/password authentication  
- Student login using roll number (and password if enabled)  
- Session-based authentication with protected routes  
- Logout functionality with proper session termination  

---

### 2. 🎒 Student Information Management
- Add new student records  
- Edit existing student data  
- Delete student entries (with confirmation)  
- Search students by **name or roll number**  
- Clean dashboard table view  
- Proper input validation and error handling  

---

### 3. 🎨 Professional UI/UX (College Portal Design)
- Modern navy blue & gold theme  
- Responsive for all devices  
- Card-based dashboard layout  
- Smooth hover animations & transitions  
- Clean typography and readable layout  
- Consistent design language throughout  

---

### 4. 📊 Dashboard Summary Cards
Dynamic statistics displayed on the admin dashboard:

- Total students  
- Highest marks  
- Average marks  
- Number of courses  
- Color-coded summary cards with gradient visuals  

---

### 5. 📤 Data Export Functionality
Export all student data to **Excel (XLSX)**:

- Auto-formatted columns  
- Clean heading structure  
- Sorted by roll number  
- Ready for offline record keeping  

---

### 6. 🗓 Attendance Management Module
A full attendance system with:

- Daily attendance marking  
- Select any date to mark attendance  
- Mark all students present/absent at once  
- Attendance history  
- Student-wise attendance percentage  
- Visual attendance analytics  

---

### 7. 👤 Student View Interface
Students can:

- View complete personal information  
- Check marks and course details  
- See attendance percentage  
- Navigate via a clean, vertical UI layout  

---

### 8. 🔒 Security Features
- Protected admin and student routes  
- Session management  
- Input validation  
- Safe form submission practices  
- Unauthorized access prevention  

---

### 9. 🔍 Search & Filtering
- Real-time search by name or roll  
- Instant filtering of dashboard table  
- Easy clear/reset functionality  

---

### 10. 📑 Professional Reporting
- Attendance report generation  
- Student performance analytics  
- Downloadable Excel sheets  
- Mark-based color coding  
- Dashboard statistical overview  

---
